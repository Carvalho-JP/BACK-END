TEORIA

O que é um Framework?

A Caixa de Ferramentas (Biblioteca)

O módulo fs ou a biblioteca de datas date-fns. Você está no controle. Você chama a ferramenta, ela faz o trabalho e te devolve o controle do fluxo.

A Fábrica (Framework)

O Framework dita as regras e o fluxo de execução. Você escreve o seu código para preencher os "buracos" que a fábrica deixou para você.

Chamamos isso de Inversão de Controle (IoC): "Não nos ligue, nós ligamos pra você".

ARQUITETURA

app.ts vs server.ts

Nunca coloque tudo em um arquivo só (index.ts). Separe o Motor da Ignição.

app.ts (O Motor)

import express from 'express';
const app = express();
app.use(express.json());

// Cadastro de Rotas
app.get('/jogadores', (req, res) => {
  res.json({ msg: "Lista" });
});

export default app;

O servidor existe, mas não está "escutando" a rede ainda. Essencial para Testes Automatizados no futuro.

server.ts (A Ignição)

import app from './app';

const PORTA = 3000;

app.listen(PORTA, () => {
  console.log("Servidor Online!");
});

Apenas importa o motor e acende a faísca na porta 3000.

MÉTODOS HTTP

A Batalha: PUT vs PATCH

Ambos servem para atualizar recursos no Banco de Dados, mas trabalham de forma bem diferente.

PUT Substituição Total

Recebe o objeto inteiro do cliente e substitui o antigo. Se o cliente esquecer de mandar o `inventário`, o servidor apagará o inventário do banco!

PUT /jogadores/1
{
  "nome": "Arthas",
  "level": 50,
  "vivo": true
}

PATCH Atualização Parcial

O Bisturi Cirúrgico. Envia apenas a propriedade que mudou. O servidor preserva todo o resto do dado intocado.

PATCH /jogadores/1
{
  "level": 51
}
